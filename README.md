### Selected work

**01 / [dacli](https://github.com/mouadja02/dacli)** &nbsp; — &nbsp; intent → tools\
A data-engineering agent for the terminal. Ask for a capability; it writes a Python extension, validates it, and loads it into the running session.

**02 / [murmur](https://github.com/mouadja02/murmur)** &nbsp; — &nbsp; voice → useful text\
A hotkey turns spoken thoughts into refined text, then pastes it at your cursor. Transcription and language models run locally.

**03 / [bitcoin dataset](https://github.com/mouadja02/bitcoin-technical-indicators-dataset)** &nbsp; — &nbsp; prices → indicators\
Hourly Bitcoin candles enriched with 70+ technical indicators, published as an open dataset for analysis and machine learning.
